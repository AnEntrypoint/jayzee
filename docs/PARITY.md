# Parity matrix

Ranked by dependency. Each row names the source it comes from and its status.

- built: a gate under scripts/ checks it, and npm test runs that gate.
- partial: some of the row is built and checked, and the rest is open.
- open: not started.
- decision: out of scope for a host-agnostic physics and netcode package, pending an owner decision.

Every path carries a namespace label. `path (spoint)` names a file in the spoint tree at d5e3860. `path (jayzee)` names a file in this repo. The cross-map checker enforces the label.

Sources are spoint at d5e3860 (INVENTORY.md and FAMILIES.md from the spoint agent), upstream's documented featureset, and the spawn learning feed (75 engine, netcode and physics learnings; 31 process learnings). Items reported by a peer and not reproduced here are marked peer-reported.
